When Preview Can Reach an Internal Service

A User Can Induce Preview to Request a Resource the User Cannot Reach.

The topology is unchanged: the user remains outside the application and private networks, while Preview runs inside the application network. The normal public fetch path is still present but de-emphasized. The user has no direct route to the internal service, yet Preview can reach it. A user-influenced internal URL can therefore make Preview send the request and relay the response. Transition with: "This kind of unintended server-side request is known as SSRF."
