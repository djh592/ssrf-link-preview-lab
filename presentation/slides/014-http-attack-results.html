Where Did Initial Validation Fail?

Initial Validation Blocked Direct Targets, but All 100 Redirect Trials Reached and Disclosed the Report.

The vulnerable baseline reached and disclosed the internal report in every direct and redirect trial. Initial-URL validation blocked both direct conditions, but it trusted the original external target and therefore failed in all 100 redirect trials. Internal access and marker disclosure were measured separately; they happen to agree for every HTTP attack in this run. Each-hop validation, check and bind, and rejecting redirects all stopped these static HTTP attack scenarios, with no unresolved trials.
