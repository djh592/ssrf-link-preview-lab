How Do We Judge Each Trial?

Security and Preview Utility Are Measured Separately Under the Same Fetch Policies.

The demo showed individual paths. The repeated evaluation contains 750 normal trials and 1,000 HTTP attack trials: 50 repetitions of every scenario-policy condition. The four recursive-DNS probes are kept separate because they are verified mechanism evidence, not a repeated-rate study. Every result remains tied to one trial ID. An internal access is counted only when internal-report logs show the matching request. Disclosure additionally requires the synthetic marker in the returned metadata and a matching internal response identity. A normal preview succeeds only when it returns the expected metadata within the task timeout; latency is summarized among successful normal tasks. Keep unresolved attempts separate from blocked attempts. The DNS probe has its own resolver and peer evidence, so it must not be merged with the GUI's application-modeled DNS sequence.
