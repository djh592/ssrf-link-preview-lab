Link Previews in Everyday Use

A Link Preview Can Make the Server Fetch a User's URL.

Link previews are something most of us use almost every day. [Click] When we send a link in a chat application, it often expands into a card like this, with a title, a short description, and an image. [Click] Behind the scenes, the browser first sends the URL to a preview service. The preview service fetches the public website and reads its page content. It then sends the preview card back to the browser. [Click] So the key point is that the server fetches a URL chosen by the user. This request comes from the server's network, and that is where the security problem begins.
