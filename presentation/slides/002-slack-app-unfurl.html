One Way to Generate a Link Preview

A Slack App Can Return a Preview After a Link Is Shared.

Use Slack as one concrete example of how a link preview can be generated, not as the subject of the project. When a message contains a link associated with an installed app, Slack sends the app a link_shared event. The app handles that event and can call chat.unfurl; Slack then renders the returned content in the original message. This is neither a universal preview architecture nor the only preview mechanism Slack supports, and it does not establish that the app fetches the linked page. Transition by contrasting it with the next slide by abstracting away the Slack-specific details and examining a simple server-side preview topology: the preview service itself fetches the submitted URL.
