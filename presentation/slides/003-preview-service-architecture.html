A Simple Link Preview Topology

The Preview Service, Not the User's Browser, Makes the HTTP Request.

Read this first as a network topology. The browser is a client endpoint, Preview runs inside an application network, and the external website is on the public Internet. The two bidirectional links show network connectivity; their labels identify the traffic carried on those links. The user submits a URL over HTTPS, while Preview performs the outbound page fetch. Transition with: "Because the request comes from Preview, it uses Preview's network access."
