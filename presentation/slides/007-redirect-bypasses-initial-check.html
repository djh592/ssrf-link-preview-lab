How Can a Redirect Bypass an Initial URL Check?

Checking Only the Submitted URL Does Not Govern the Redirected Request.

The submitted URL points to a public host and passes the initial check. Preview requests that host, which returns an ordinary HTTP 302 response with a private URL in its Location header. A redirect-following client then creates a second request. If that new destination is not checked, the request can reach the private service. The public website does not contact the private service; both HTTP requests originate from Preview. Redirects are normal web behavior—the failure is applying policy only to the first target. Transition with: "A redirect changes the destination explicitly in an HTTP response. But the effective destination can also change without changing the hostname."
