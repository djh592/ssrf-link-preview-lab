The design follows three choices. First, every attack target is synthetic and runs inside a bounded Docker environment, so we can repeat the attacks without touching real private services. Second, the request pipeline stays fixed while only the policy changes. Every policy uses the same redirect handling, metadata parser, and PycURL transport, which makes the comparison meaningful. Third, we observe both sides of a request. The preview trace records decisions and connected peers, while the destination services independently record what arrived; a trial ID joins those observations.
