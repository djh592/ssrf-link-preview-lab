Link Preview as a Network Boundary

Expected Preview fetches public pages.
Network boundary The browser cannot directly reach the internal report.
Privileged fetcher The Preview Service Can Reach What the User Cannot.

A documented Synology Chat link-preview vulnerability allowed authenticated users to access intranet resources.

CVE-2017-11148 · CWE-918

Is checking the submitted URL enough to control every connection that follows?

Start with the normal behavior: the browser submits a URL and the preview service fetches a public page. Advance to add the protected network. The browser has no direct route to the internal report, so its attempted path stops at the boundary. Advance again: the preview service occupies a more privileged network position and may be induced to make the internal request. The red preview-to-report path is an illustrative request, not a measured run or proof of disclosure. Advance again for the real-product evidence: Synology's advisory documents a failed link-preview boundary, but does not establish a redirect or DNS mechanism.
